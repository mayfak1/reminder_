# Backend REST API — Сервис напоминаний (Reminder)

Реализация серверной части приложения для управления персональными напоминаниями с интеграцией отправки уведомлений через Email и Telegram.



---

## 🛠 Технологический стек

При разработке серверной части используются следующие технологии:

* **Язык программирования:** Java
* **Фреймворк:** Spring Boot
* **Безопасность:** Spring Security OAuth2
* **База данных:** PostgreSQL
* **ORM:** Hibernate
* **Миграции БД:** Liquibase
* **Сборщик проекта:** Gradle / Maven
* **Планировщик задач:** Quartz / `@Scheduled`
* **Конфигурация:** YAML формат
* **Контейнеризация:** Docker & Docker Compose
* **Тестирование:** Функциональные и интеграционные тесты

---

## 📝 Описание функционала

Суть проекта заключается в том, что пользователь после авторизации попадает на главную страницу и может управлять своим списком напоминаний.

**Основные возможности:**
* Создание новых напоминаний.
* Редактирование существующих записей.
* Удаление напоминаний.
* Поиск по названию, описанию, дате и времени.
* Пагинация списков.
* Сортировка по названию, дате или времени.
* Фильтрация по дате и времени.
* **Уведомления:** При наступлении заданного времени приложение автоматически отправляет уведомление (Заголовок + Описание) на Email и в Telegram пользователя. Настройки контактов берутся из профиля пользователя.

---

## 💾 Структура данных (Сущность Reminder)

В миграциях базы данных обязательно должны быть прописаны каскады (`ON DELETE CASCADE` / `ON UPDATE CASCADE`).

| Название поля | Тип данных | Описание |
| :--- | :--- | :--- |
| `id` | `bigint` | Уникальный идентификатор (Primary Key) |
| `title` | `varchar(255)` | Краткое описание / Заголовок |
| `description` | `varchar(4096)` | Полное описание |
| `remind` | `datetime` | Дата и время напоминания в формате ISO |
| `user_id` | `bigint` | Идентификатор пользователя (Внешний ключ) |

## 🌐 Спецификация API

Вышеописанные эндпоинты являются виртуальными. Логика, структура запросов и ответов реализуется разработчиком на свое усмотрение.

### Управление напоминаниями
* **Создание:** `POST https://domain/api/v1/reminder/create`
* **Удаление:** `DELETE https://domain/api/v1/reminder/delete`

### Вывод и фильтрация данных
* **Список с пагинацией:** `GET https://domain/api/v1/list`
  * Параметры: `{ total, current }`
* **Сортировка:** `GET https://domain/api/v1/sort`
  * Параметры: `{ by: name | date | time }`
* **Фильтр:** `GET https://domain/api/v1/filtr`
  * Параметры: `{ date | time }`
